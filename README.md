## 🧠 About Me

> *"The best AI engineer is the one who ships — not the one who theorises."*

Azure AI Engineer in Melbourne. I build **agents that answer from real sources**, and the **evaluation harnesses that show whether they actually do**.

Right now I'm building the AI platform at a Melbourne travel operator: a shared agent layer on Azure AI Foundry sitting behind a voice call bot, website and WhatsApp assistants, and internal knowledge retrieval. Most of the work is the unglamorous half — grounding, guardrails, tool boundaries, and the regression suite that has to pass before a prompt change ships.

Before AI I worked on embedded systems and hardware QA. That background is why I reach for a test harness before a demo.

- 🤖 **Currently:** A production voice agent on Azure AI Foundry — grounding, guardrails, and the suite that gates every change
- 🎓 **Certifications:** Microsoft AI-102 | AI-900 | AZ-900 (AZ-104 in progress)
- 🛠️ **Background:** AI Engineering · Embedded Systems · Hardware & SaaS QA · Cloud DevOps
- 📍 **Based in:** Melbourne, Australia 🇦🇺
- 🎯 **Mission:** Shipping intelligent systems that solve real-world problems — not toy demos

## 🚀 Projects

### 🔍 [azure-ai-agent-eval](https://github.com/sai-cheruvu/azure-ai-agent-eval)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Azure OpenAI](https://img.shields.io/badge/Azure_OpenAI-0078D4?style=flat-square&logo=microsoftazure&logoColor=white)
![CI](https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat-square&logo=githubactions&logoColor=white)

A grounded Azure OpenAI agent with the evaluation suite that proves it works. Hybrid BM25 and vector retrieval fused with RRF, a grounding gate that makes the agent refuse rather than improvise, and a golden set wired into CI. Runs end to end with no Azure key, so the suite is a real gate on every pull request.

### 🔐 [graph-agent-toolkit](https://github.com/sai-cheruvu/graph-agent-toolkit)

![MSAL](https://img.shields.io/badge/MSAL-5391FE?style=flat-square&logo=microsoft&logoColor=white)

Microsoft Graph as agent tools, with least privilege enforced in code rather than trusted to the prompt. Scopes checked against the token's real claims, writes off by default, audit log with message bodies redacted.
